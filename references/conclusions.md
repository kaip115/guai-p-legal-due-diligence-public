# 从材料到结论

| 材料状态 | 报告写法 |
| --- | --- |
| 事实已核 | 写明证据、时点与可确认的事实。需判断法律效果时，再核查适用法与要件。 |
| 公司说明 | 写明陈述人、日期和覆盖事项。未另行检索时，不表述为核查团队独立发现。 |
| 文件存在差异 | 分列两份材料的记载和各自作用；先核主体、版本、计量单位、期间。 |
| 证据有缺口 | 先答能回答的部分。指出缺什么、为何影响判断、由谁补。 |
| 距基准日或出具日尚早 | 写材料实际覆盖到哪天，另列需要更新的事项。 |

## 离线播放授权
已签许可只覆盖在线播放。正文应写「现有许可未授权离线播放」，不写「目标公司侵权」，因为拟议功能尚未上线。其后取得授权时，核对作品、期限、地域、使用方式和生效日，再同步修改摘要、正文、资料附件及开列的待办。

## 收到凭证后核对归属
公司说订阅渠道甲的预付款已退。新取得的银行单据指向渠道乙。乙的款项可按该单据记载；甲仍为公司陈述，不能因两笔金额相等就认定已退。更正摘要、金额表和凭证索引。只针对渠道甲索取可匹配付款的记录。

## 设立时记录不证明当前状态
设立文件能证明所载初始股权。早于基准日的名册只能说明该日的记载。期间股权变更另核文件；基准日股权应与覆盖该日的名册、表决安排和必要的确认相互核对。
