# 可选报告框架

## 收购
1. 委托范围和基准日
2. 影响估值、交割及交割后安排的主要发现
3. 主体、股权及授权
4. 经营、关键合同、知识产权及数据
5. 用工、争议或其他已纳入范围的事项
6. 所阅资料与未决事项

## 运营专项复核
1. 核查问题、对象、期间和取样口径
2. 对应事实、证据及差异
3. 依调查范围列示需调整的事项和后续核查
4. 样本或证据索引

## 上市子公司
1. 委托与法域
2. 主要发现
3. 主体和股权、维持经营所需权利或许可、重大合同等约定事项
4. 上市批准及无冲突核查
5. 与披露有关的问题、待补材料及审阅索引

不为填齐目录而扩大委托。未纳入范围的主题直接删除。
