# 定稿表述对照

以下句子均为虚构示范。

| 场景 | 改写前 | 改写后 |
| --- | --- | --- |
| 委托范围 | 我们对公司各方面作了全面的尽职调查。 | 本次审阅按委托附件所列事项进行，基准日为2026年9月30日。 |
| 文件已核 | 经全面核查，客户合同事项基本正常。 | 签署版服务合同约定，控制权变更前至少20日须书面通知客户。 |
| 公司陈述 | 未发现诉讼及仲裁。 | 公司书面确认，截至基准日无未决诉讼或仲裁。尚未作独立检索。 |
| 证据差异 | 工资有问题，待公司补材料。 | 客服样本有一笔值班记录。现有工资明细未能对应这笔记录。 |
| 补证后同步 | 离线播放授权仍待确认。 | 补充协议自约定生效日起允许离线播放两部作品。第三部不在授权清单内。 |
| 删去推测 | 获授权在线播放，因此下载应当也没问题。 | 现行合同允许在线播放，未授权下载。 |

一句写清一件事。先区分事实、公司陈述和判断，再删重复语句。将需要公司做的具体动作放进补件列或审阅批注。
